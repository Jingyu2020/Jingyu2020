# Hi, I'm Jingyu 👋

I build automated laboratories and the AI that runs them.

I'm the Facility Manager of **[DIGIBAT](https://www.imperial.ac.uk/digibat/)** at Imperial College London, the UK's first fully automated energy research facility. I built it from scratch, and in its first year it supported over 50 research projects. I'm now building the facility's digital twin: an AI-assisted platform that runs the lab as one auditable system and carries out agentic actions to assist research.

### What I work on

- 🤖 **Lab automation:** robotic synthesis, electrolyte formulation, coin- and pouch-cell assembly, parallel electrocatalysis with online HPLC, and battery cycling, all under software control
- 📖 **Ontologies for lab robots:** writing down what a lab knows (which tube goes where, what a syringe holds, what you must never do) in OWL, a format that people and LLMs can both read and that can be checked automatically
- 🪞 **Digital twins:** simulated copies of lab equipment, so a program can be run and checked before it reaches real hardware
- 🧠 **AI agents on real hardware:** fail-safe actuation, permission gates, audit trails, and pre-registered evaluations, in place before an agent touches a machine
- 🔍 **Honest AI lab agents:** finding out when models hide failures and claim work is done, and building detectors that catch it
- ⚡ **Energy materials:** PhD in Chemical Engineering (Imperial), working on PGM-free electrocatalysts, carbon nanomaterials, and sodium-ion batteries

### Projects

| Project | What it is |
|---|---|
| [The Robot's Dictionary](https://jingyu2020.github.io/robot-dictionary/) | Interactive explainer for ColourMix v3. An ontology of a colour-mixing robot taught 11 LLMs to program its syringe pumps, with every program run on a digital twin of the pumps. On their own, the nine reasoning models got the job right 32% of the time; with the ontology, 100%. You can write the program yourself on the page. |
| [lab-agent-safety](https://github.com/AIxScience-Hack/lab-agent-safety) | London AI × Science Hackathon (2026). A virtual lab with planted failures for testing whether AI agents report problems honestly. I built the environment, the honeypots, and the scorer. |
| [AutoCatX](https://github.com/digibatatimperial/AutoCatX) | Control code for DIGIBAT's automated electrocatalysis platform: liquid handling, temperature control, electrochemical testing, and online product analysis |
